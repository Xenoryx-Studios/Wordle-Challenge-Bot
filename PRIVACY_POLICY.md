# Privacy Policy

**Last updated: 2026-08-13**

This Privacy Policy explains what data the official instance of the Wordle Challenge Bot ("the Bot"), operated by Xenoryx Studios, collects and how it is used.

## 1. Open Source Software

The Bot's source code is public, and anyone may self-host their own independent instance. **This Privacy Policy applies only to the official instance operated by Xenoryx Studios.** If you're using a self-hosted instance run by someone else, their operator is responsible for how that instance handles data — we have no access to or control over independently run instances.

## 2. What Data We Collect

The Bot stores only **server-level configuration data**, per Discord server (guild):

- The channel ID where the Bot posts the daily word
- Your configured posting schedule (hour, minute, and IANA timezone)
- The current day's word, the running history of previously used words for that server, and the ID of the discussion thread created for the current word

**We do not collect:**
- Message content (the Bot does not use Discord's Message Content intent)
- Individual user identities, usernames, or user IDs
- Direct messages
- IP addresses or device information
- Any data beyond what's needed to operate the daily-posting feature described above

Nothing about *who* runs a command or *who* participates in a server's Wordle thread is recorded by the Bot.

## 3. How We Use Data

The data described above is used solely to operate the Bot's core feature: posting a starter word on your configured schedule and avoiding repeats.

## 4. How Data Is Stored

Data is stored as a plain file on the server(s) operated by Xenoryx Studios that run the official instance of the Bot. **We do not share, sell, or disclose this data to any third party** for advertising, marketing, or any other purpose.

## 5. Data Retention and Deletion

A server's configuration is retained for as long as the Bot remains in that server. Removing the Bot from your server does not automatically delete existing stored data; to request deletion of your server's data from the official instance, contact us via [GitHub Issues](https://github.com/Xenoryx-Studios/Wordle-Challenge-Bot/issues) with your server (guild) ID.

## 6. Children's Privacy

We do not knowingly collect personal information from anyone. Since the Bot only stores the server-level configuration described in Section 2 — never data tied to an individual user — there is no personal information to collect from any user regardless of age. Discord itself requires users to meet its own minimum age requirements per its [Terms of Service](https://discord.com/terms).

## 7. Your Rights (GDPR / Regional Privacy Laws)

Because the Bot does not process personal data about individual users, most obligations under regulations like the EU/EEA's GDPR do not apply to how it operates. The only data held is server-level configuration, controllable by whoever administers that Discord server (see Section 5 for how to request deletion).

## 8. Changes to This Policy

We may update this Privacy Policy from time to time. Material changes will be reflected by updating the "Last updated" date above.

## 9. Contact

Questions about this Privacy Policy, or requests to delete your server's data from the official instance, can be raised via [GitHub Issues](https://github.com/Xenoryx-Studios/Wordle-Challenge-Bot/issues) on the project's repository.
